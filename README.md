# Altyn Adam — Золотой Человек

Линейная action-adventure игра в духе Assassin's Creed II про эпоху саков. Unreal Engine 5.8, один разработчик, агенты Claude Code.

Сейчас делается вертикальный срез: Акты 1.1–1.2 (обычный день в стане Золотого Народа и ночное нападение).

## Как идёт работа

В Claude Code, в папке проекта, при открытом Unreal Editor:

```
/next-task       взять следующую задачу и получить план
/ue-checkpoint   сохранить состояние перед работой в редакторе
/done            ревью, отметка в плане, запись в журнал, pull request
/gdd-check       сверить текст или сцену с дизайн-документом
```

Проверка репозитория: `bash scripts/check-repo.sh`.
