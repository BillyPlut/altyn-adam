# 0001. Unreal Engine 5.8 и официальный MCP-плагин Epic

Статус: принято · 2026-11-15

## Контекст
Разработчик один и новичок в Unreal. Нужен способ, при котором агенты работают прямо в редакторе, а не только пишут текст.

## Решение
Используем Unreal Engine 5.8 и плагин `unreal-engine-skills-for-claude-code` из официального каталога плагинов Claude Code. Плагин включён в `.claude/settings.json`.

## Последствия
- Версия движка зафиксирована: MCP-плагин Epic появился в 5.8.
- Плагин экспериментальный: возможны изменения и сбои. Запасной путь — ручная работа в редакторе по инструкциям агента.
- Доступ агента к редактору равен запуску кода: действуют правила безопасности из `AGENTS.md`.
