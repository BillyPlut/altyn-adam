# 0002. Проект Unreal в корне репозитория

Статус: принято · 2026-11-15

## Контекст
Редактор создаёт `.mcp.json` рядом с `.uproject`. Claude Code читает `.mcp.json` и `.claude/` из папки, в которой запущен.

## Решение
`AltynAdam.uproject`, `Config/`, `Content/`, `Source/` лежат в корне репозитория рядом с `docs/` и `.claude/`.

## Последствия
Один корень для редактора, Claude Code и git. Документы и Harness видны агенту без дополнительных настроек.
