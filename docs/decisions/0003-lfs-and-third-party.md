# 0003. Свои ассеты в Git LFS, сторонние наборы вне git

Статус: принято · 2026-11-15

## Контекст
Ассеты Unreal бинарные и большие. Квота Git LFS на GitHub ограничена. Лицензии наборов с Fab обычно не разрешают распространение исходных файлов.

## Решение
- Всё своё в `Content/AltynAdam/` и `SourceArt/` хранится через Git LFS.
- Сторонние наборы кладутся в `Content/ThirdParty/`, папка исключена из git. Источник, версия и лицензия записываются в `docs/third-party-assets.md`.

## Последствия
- Репозиторий остаётся небольшим.
- После свежего клонирования сторонние наборы нужно скачать заново по списку.
- Резервная копия `Content/ThirdParty/` — ответственность владельца (внешний диск или облако).
