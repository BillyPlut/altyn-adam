# 0004. Гибрид: логика в C++, настройка в Blueprint

Статус: принято владельцем · 2026-11-15

## Контекст
В GDD v1.1 записано: «Разработка ведётся на Blueprints, переход на C++ — только там, где это действительно нужно». Это решение принималось до появления агентов в проекте.

С агентами расчёт другой:
- C++ — текст. Агент пишет его напрямую, каждое изменение видно в git и проходит ревью.
- Blueprint — бинарный файл. Агент может менять его через редактор, но изменение в git не читается.

## Варианты
1. **Гибрид (выбран).** Проект создаётся как C++. Системы пишутся на C++, значения и содержимое настраиваются в Blueprint и Data Asset. Требует установки Visual Studio с компонентами для разработки игр.
2. **Только Blueprint (отклонён).** Проще старт, ничего не нужно ставить. Изменения агентов непрозрачны, ревью почти невозможно.

## Решение
Проект создаётся как C++. Логика систем пишется на C++, значения и содержимое настраиваются в Blueprint и Data Asset. Это уточняет формулировку GDD v1.1 «разработка ведётся на Blueprints»: сам GDD не меняется, приоритет у этой записи.

## Последствия
- Нужна одна дополнительная установка на этапе M0.
- Владелец учится читать простой C++ на этапе M1. Писать его самому не обязательно.
- На этапе M0 проект создаётся сразу как C++ (шаблон Third Person, тип C++).
