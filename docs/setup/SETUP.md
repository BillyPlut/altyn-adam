# Установка с нуля

Инструкция для владельца. Это задачи M0-01 … M0-07 из `PLAN.md`: их нужно сделать руками один раз. После шага 7 остальное делает агент.

Что уже готово: репозиторий, правила для агентов, Harness. Плагин Epic уже прописан в `.claude/settings.json`, отдельно скачивать его не нужно.

## Шаг 1. Программы

1. **Git** и **Git LFS**. На Windows установите Git for Windows: вместе с ним ставится Git Bash, он нужен защитным хукам проекта и хуку плагина Epic. Git LFS обычно входит в установщик.
2. **Claude Code**. Актуальная инструкция по установке: <https://docs.claude.com/en/docs/claude-code/overview>.
3. **Unreal Engine 5.8** — уже установлен.
4. **Visual Studio с компонентами для разработки игр на C++** (на Windows). Нужна, потому что логика игры пишется на C++ (решение 0004). В установщике Visual Studio выберите набор «Разработка игр на C++». На macOS вместо неё нужен Xcode.

Проверка в терминале (на Windows — в Git Bash):

```
git --version
git lfs version
bash --version
claude --version
```

## Шаг 2. Клонировать репозиторий

Репозиторий приватный, поэтому понадобится вход в GitHub. Проще всего через GitHub Desktop или GitHub CLI (`gh auth login`).

```
git clone https://github.com/<ваш-логин>/altyn-adam.git
cd altyn-adam
git lfs install
```

Выберите короткий путь без пробелов и кириллицы, например `D:\Dev\altyn-adam`. Unreal плохо переносит длинные пути.

## Шаг 3. Создать проект Unreal

1. Запустите Unreal Engine 5.8 → **Games** → шаблон **Third Person**.
2. Тип проекта: **C++**.
3. Starter Content — выключить.
4. Имя проекта: `AltynAdam`. Папку выберите любую временную.
5. Дождитесь открытия редактора и закройте его.
6. Перенесите **содержимое** созданной папки `AltynAdam` (файл `AltynAdam.uproject`, папки `Config`, `Content`, `Source`) в корень клонированного репозитория, рядом с `AGENTS.md`. Папки `Saved`, `Intermediate`, `Binaries`, `DerivedDataCache` переносить не нужно.
7. Откройте `AltynAdam.uproject` уже из папки репозитория.

## Шаг 4. Включить плагины в редакторе

**Edit → Plugins**, в поиске наберите `MCP`. Включите:

- **Unreal MCP** (внутреннее имя `ModelContextProtocol`),
- **All Toolsets** (без него сервер не даёт ни одного инструмента).

Оба плагина экспериментальные, редактор об этом предупредит. Перезапустите редактор.

## Шаг 5. Запустить сервер MCP

Откройте консоль редактора (клавиша `` ` `` или поле Cmd в окне **Window → Output Log**) и выполните:

```
ModelContextProtocol.StartServer
```

В Output Log должны появиться сообщения о запуске сервера. По умолчанию это порт 8000, адрес `/mcp`.

## Шаг 6. Создать конфигурацию для Claude Code

В той же консоли:

```
ModelContextProtocol.GenerateClientConfig ClaudeCode
```

В корне проекта появится файл `.mcp.json`. Он хранится в git.

## Шаг 7. Открыть проект в Claude Code

1. Редактор оставьте открытым.
2. В терминале, в папке репозитория, запустите `claude`.
3. Подтвердите доверие к папке. Claude Code предложит установить плагин `unreal-engine-skills-for-claude-code` — согласитесь.
4. Выполните `/plugin`: на вкладке Installed плагин должен быть включён.
5. Выполните `/mcp`: в списке должен быть `unreal-mcp`.
6. Напишите: «Перечисли все акторы на текущем уровне». Если агент вернул список — всё работает.

Дальше напишите агенту `/next-task`. Он возьмёт задачу M0-08.

## Каждый рабочий день

1. Открыть `AltynAdam.uproject`.
2. Запустить сервер: `ModelContextProtocol.StartServer` (или один раз включить автозапуск, см. `skills/unreal-mcp/references/setup.md` в плагине Epic).
3. Запустить `claude` в папке репозитория.
4. `/next-task`.

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| Claude Code не предложил плагин | Выполнить `/plugin install unreal-engine-skills-for-claude-code@claude-plugins-official`. Если каталога нет: `/plugin marketplace add anthropics/claude-plugins-official`, затем повторить |
| В `/mcp` нет `unreal-mcp` | Проверить, что редактор открыт, сервер запущен (шаг 5) и `.mcp.json` лежит в корне (шаг 6). Перезапустить `claude` |
| Порт 8000 занят | `ModelContextProtocol.StartServer 8001`, затем снова шаг 6 |
| Хуки не срабатывают на Windows | В системе нет `bash`. Установить Git for Windows или запускать Claude Code из Git Bash |
| Хук просит чекпойнт | Это нормально: выполнить `/ue-checkpoint` |
| В `git status` тысячи файлов | В git попал кэш. Проверить, что `.gitignore` из репозитория на месте, ничего не коммитить, спросить агента |

## Безопасность

Плагин даёт агенту живой доступ к редактору. По сути это запуск кода на вашем компьютере, поэтому:

- не запускайте Claude Code с флагом `--dangerously-skip-permissions`, пока плагин включён;
- не запускайте сервер MCP на общем или чужом компьютере и не открывайте порт наружу;
- сохраняйте и коммитьте работу перед длинной сессией (за этим следит хук);
- просматривайте изменения перед слиянием pull request.
