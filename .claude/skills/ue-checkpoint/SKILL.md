# Чекпойнт перед работой в редакторе

Инструменты `unreal-mcp` меняют живые объекты редактора и могут изменить, переместить или удалить ассеты одним вызовом. Чекпойнт делает любую такую правку обратимой.

1. Попроси владельца сохранить всё в редакторе (File → Save All), если там есть несохранённые изменения. Сам через MCP можешь сохранить только после того, как он подтвердит.
2. Посмотри `git status`.
   - Чисто — сообщи «чекпойнт не нужен, дерево чистое» и продолжай работу.
   - Есть изменения — перейди к шагу 3.
3. Проверь, что среди изменений нет лишнего: `Saved/`, `Intermediate/`, `Binaries/`, `DerivedDataCache/`, `Content/ThirdParty/`, файлы с секретами. Если есть — остановись и сообщи: значит, сломан `.gitignore`.
4. Покажи владельцу короткий список изменённых файлов.
5. Выполни:
   ```
   git add -A
   git commit -m "checkpoint: before editor session (<ID задачи>)"
   ```
6. Убедись, что `git status` чист, и продолжай.

Как вернуться к чекпойнту, если что-то пошло не так: закрыть редактор, затем откатить конкретные файлы командой `git restore <путь>` или вернуть ветку к коммиту-чекпойнту. Команды `git reset --hard` и `git clean` заблокированы хуком, их выполняет только владелец вручную и только осознанно.
